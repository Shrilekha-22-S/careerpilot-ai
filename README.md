# CareerPilot AI

An AI-powered placement preparation platform designed to help students assess their job readiness, identify skill gaps, improve resumes, and prepare for technical interviews.

## Project Goals

- Analyze resumes and suggest improvements.
- Track technical skills and learning progress.
- Recommend skills and preparation roadmaps.
- Support placement and interview preparation.
- Provide personalized career guidance.

## Planned Technology Stack

- **Frontend:** React, TypeScript, Vite
- **Backend:** Python, FastAPI
- **Database:** PostgreSQL
- **AI:** Resume analysis and interview preparation

## Project Status

Currently in the initial setup and planning phase.
